Déclaration de confidentialité

Ceci est la déclaration de confidentialité d’Aircrete Systems BV (Aircrete). Cette déclaration s’applique à toutes les informations que nous traitons à partir des visiteurs de notre site web et de nos clients (potentiels). Nous accordons une grande importance à la protection de la vie privée et nous sommes attentifs aux données personnelles collectées. Dans cette déclaration, nous expliquons, entre autres, quelles informations personnelles nous recueillons auprès des visiteurs du site web et des clients (potentiels), comment nous recueillons ces données personnelles et pendant combien de temps elles sont conservées. Nous indiquons également les droits dont vous disposez en ce qui concerne les données à caractère personnel que nous collectons auprès de vous.

Quelles données personnelles traitons-nous et pourquoi traitons-nous ces données ?

Clients (potentiels)

Le traitement des données personnelles des clients (potentiels) nous est nécessaire, par exemple pour exécuter les commandes, répondre aux questions d’un client (potentiel) sur nos produits et exécuter les demandes de réparation. Afin d’exécuter un contrat avec un client, nous traitons les coordonnées, le nom de l’entreprise, les données de paiement, les données de facturation, les produits commandés et les données relatives à l’emploi. Sans ces informations, nous pourrions ne pas être en mesure de mettre en œuvre l’accord conclu avec vous ou votre entreprise.

Nous traitons également les coordonnées des clients potentiels, le nom de l’entreprise, la fonction, le numéro de téléphone, l’adresse électronique, les centres d’intérêt et les données personnelles qui peuvent être incluses dans une question ou un message qui nous est adressé. Nous traitons ces données personnelles sur la base de notre intérêt légitime. Nous avons besoin de ces informations pour mener à bien nos activités commerciales normales.

Bulletin d’abonnement

Pour vous envoyer notre lettre d’information par courrier électronique, nous avons besoin de votre adresse électronique. Nous pouvons utiliser votre adresse électronique pour l’envoi de notre lettre d’information, si vous nous en donnez l’autorisation.

Formulaire de contact

Le formulaire de contact vous permet de nous poser des questions, d’introduire des réclamations et de demander des informations supplémentaires sur nos produits et services. Nous recueillons votre nom et votre adresse électronique. Il est également possible que vous introduisiez des données personnelles dans le message que vous nous envoyez. Nous collectons ces informations personnelles sur la base de notre intérêt légitime. Sans ces informations, nous ne pouvons pas répondre (correctement) à votre question. Vous pouvez également saisir (sans obligation) d’autres informations : le nom de votre entreprise et des informations sur les produits et/ou services qui vous intéressent. Nous traitons ces informations sur la base de votre consentement.

Retrait de l’autorisation

Si nous fondons le traitement de vos données personnelles sur votre consentement, vous pouvez retirer ce consentement à tout moment en envoyant un e-mail à info@aircrete.com. Toutefois, le retrait de votre consentement n’affecte pas la légalité du traitement de vos données à caractère personnel avant le retrait.

Sécurité des données

Comme nous l’avons mentionné, nous attachons une grande importance à la prudence dans le traitement des données personnelles. Cela inclut la sécurité des données personnelles que nous collectons. C’est pourquoi des mesures techniques et organisationnelles appropriées ont été prises au sein d’Aircrete pour protéger les données personnelles collectées.

Combien de temps les données personnelles sont-elles conservées ?

Notre principe de base est que nous ne conservons pas vos données personnelles plus longtemps que nécessaire pour l’objectif pour lequel ces données ont été collectées à l’origine. Par exemple, si vous supprimez votre compte ou si vous vous désabonnez de notre lettre d’information, nous supprimerons les données collectées à cette fin. Il est possible de déroger à ce principe, par exemple si une autre période de conservation est prescrite sur la base de la législation et de la réglementation.

Transfert de données à caractère personnel à des tiers

Dans certains cas, nous devons faire appel à des tiers pour nous aider à mener à bien certaines activités. Les catégories de tiers auxquels nous transmettons des données à caractère personnel sont les suivantes :

– Organiser des fêtes ;

– Google Analytics

(Voir notre page Politique en matière de cookies pour savoir ce que sont les cookies et comment les désactiver).

Vos droits

Vous pouvez exercer les droits suivants en ce qui concerne les données personnelles que nous traitons à votre sujet :

– Demander l’accès aux données personnelles que nous avons collectées auprès de vous.

– Faire corriger les erreurs dans les données personnelles.

– Faire supprimer les données personnelles.

– Limiter le traitement de vos données personnelles.

– Nous vous demandons de transférer vos données personnelles à une autre organisation.

Vous pouvez également vous opposer à ce que nous utilisions vos données personnelles.

Si vous souhaitez exercer (l’un des) droits susmentionnés, vous pouvez nous contacter aux coordonnées figurant au bas de la présente déclaration de confidentialité. Nous pouvons alors vous demander de fournir des informations supplémentaires afin de confirmer votre identité.

Déposer une plainte

Si vous n’êtes pas satisfait de la manière dont nous traitons vos données personnelles, vous pouvez à tout moment déposer une plainte auprès du superviseur. Il s’agit de l’autorité néerlandaise de protection des données aux Pays-Bas. Sur le site www.autoriteitpersoonsgegevens.nl, vous trouverez de plus amples informations sur les modalités de dépôt d’une plainte.

Ajustements

Il est possible qu’Aircrete ajuste sa politique en matière de données personnelles. Si cela a des conséquences sur la manière dont Aircrete traite vos données personnelles, nous modifierons la présente déclaration de confidentialité. La dernière version de la déclaration de confidentialité sera toujours publiée sur notre site web. Nous vous recommandons donc de visiter cette page de temps en temps.
