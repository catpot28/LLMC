Häufig gestellte Fragen
Wie kann ich eine Modellanpassung und eine private Bereitstellung anfragen?
Cohere bietet maßgeschneiderte Modellanpassungen für unsere Unternehmenskunden sowie die private Bereitstellung aller unserer Produkte an. Die individuellen Preise basieren auf Ihren Unternehmensanforderungen. Weitere Informationen zur Anpassung finden Sie
hier
und zur privaten Bereitstellung
hier
.
Wie erhalte ich einen Test-API-Schlüssel?
Wenn Sie ein Konto erstellen, generieren wir automatisch einen Test-API-Schlüssel für Sie. Dieser API-Schlüssel wird Ihnen im Dashboard zum Kopieren angezeigt, sowie im Dashboard-Bereich „API-Schlüssel“.
Wie erhalte ich einen Produktions-API-Schlüssel?
Um einen Produktionsschlüssel zu erhalten, benötigen Sie Besitzerberechtigungen (oder bitten Sie den Besitzer Ihrer Organisation, die folgenden Schritte auszuführen). Navigieren Sie zur Seite „Abrechnung und Nutzung“ in Ihrem Cohere-Dashboard. Klicken Sie auf die Schaltfläche „Ihren Produktionsschlüssel erhalten“ und füllen Sie den Workflow „Go to Production“ aus.
Was ist der Unterschied zwischen einem Test-API-Schlüssel und einem Produktions-API-Schlüssel?
API-Aufrufe mit einem Test-API-Schlüssel sind kostenlos. Testschlüssel unterliegen jedoch einer Ratenbegrenzung und dürfen nicht für Produktions- oder kommerzielle Zwecke verwendet werden. API-Aufrufe mit einem Produktions-API-Schlüssel werden auf Pay-as-you-go-Basis abgerechnet. Produktions-API-Schlüssel sind für den groß angelegten Produktionseinsatz konzipiert.
Gibt es bei der Anmeldung Einschränkungen für das Konto?
Jedes Konto beginnt als persönliches Konto und hat nur Zugriff auf Test-API-Schlüssel. Als persönliches Konto können Sie keine anderen Mitglieder hinzufügen, bis Sie Teil einer Organisation werden.
Was ist der Unterschied zwischen einer Organisation und einem persönlichen Konto?
Bei Cohere ist eine Organisation eine Gruppe von persönlichen Konten, die eine gemeinsame Abrechnungsplattform nutzen. Organisationen erhalten nicht automatisch Zugriff auf Produktions-API-Schlüssel, und ein Mitglied der Organisation muss weiterhin unser Antragsformular für den Produktionszugang ausfüllen. Persönliche Konten können keine Abrechnungsinformationen mit anderen Konten teilen.
Welches Modell sollte ich auswählen?
Ihre Modellwahl spiegelt Ihre relative Priorisierung von Modellleistung und Geschwindigkeit wider. Größere Modelle bieten bessere Leistung und sind in der Lage, komplexere Aufgaben zu bewältigen, während kleinere Modelle schnellere Antwortzeiten haben.
Wann werde ich abgerechnet?
API-Aufrufe mit einem Test-API-Schlüssel sind kostenlos. API-Aufrufe mit einem Produktionsschlüssel werden auf Pay-as-you-go-Basis abgerechnet. Ihre Rechnung wird am Ende eines jeden Kalendermonats oder wenn Sie einen offenen Saldo von 250 $ erreichen, ausgestellt.
Der von mir verwendete Endpunkt wird nach Token abgerechnet. Was ist ein Token?
Sprachmodelle verstehen „Tokens“ anstelle von Zeichen oder Bytes. Die Anzahl der Token pro Wort hängt von der Komplexität des Textes ab. Einfache Texte erreichen im Durchschnitt etwa 1 Token pro Wort, während komplexe Texte weniger gebräuchliche Wörter verwenden können, die im Durchschnitt 3–4 Token pro Wort erfordern. hier
.
Wo finde ich die Preisgestaltung für unsere Legacy-Modelle?
Für bestehende Kunden:
Command-Preisgestaltung: 1,00 $/1 Mio. Token für die Eingabe und 2,00 $/1 Mio. Token für die Ausgabe
Command-light-Preisgestaltung: 0,30 $/1 Mio. Token für die Eingabe und 0,60 $/1 Mio. Token für die Ausgabe
Command R 03-2024 Preisgestaltung: 0,50 $/1 Mio. Token für die Eingabe und 1,50 $/1 Mio. Token für die Ausgabe
Command R+ 04-2024 Preisgestaltung: 3,00 $/1 Mio. Token für die Eingabe und 15,00 $/1 Mio. Token für die Ausgabe
Command R+ 08-2024 Preisgestaltung: 2,50 $/1 Mio. Token für die Eingabe und 10,00 $/1 Mio. Token für die Ausgabe
Wie hoch sind die Kosten für den Zugriff auf die Forschungsmodelle Aya über die API?
Aya Expanse-Modelle (8B und 32B) auf der API werden mit 0,50 $/1 Mio. Token für die Eingabe und 1,50 $/1 Mio. Token für die Ausgabe berechnet. Weitere Informationen zu den Aya-Modellen finden Sie
hier
.
Wie wird eine „Suche“ für die Rerank-Preisgestaltung definiert?
Eine einzelne Suchanfrage wird als eine Abfrage mit bis zu 100 zu reihenden Dokumenten definiert.
Wenn ein Dokument mehr als 500 Token enthält (einschließlich der Länge der Suchanfrage), wird es automatisch in mehrere Teile aufgeteilt. Jeder Teil wird als einzelnes Dokument behandelt und auf die Gesamtzahl der für diese Suche gereihten Dokumente angerechnet.
Dies gewährleistet eine konsistente Leistung und eine genaue Preisgestaltung bei der Arbeit mit längeren Dokumenten.
