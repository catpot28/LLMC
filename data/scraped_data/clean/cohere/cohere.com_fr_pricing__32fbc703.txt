Questions fréquentes
Comment puis-je me renseigner sur la personnalisation des modèles et le déploiement privé ?
Cohere prend en charge la personnalisation des modèles pour ses entreprises clientes, ainsi que le déploiement privé de tous ses produits. La tarification personnalisée est basée sur les besoins de votre entreprise. En savoir plus sur la personnalisation

Comment obtenir une clé API d’essai ?
Lors de la création d’un compte, nous créons automatiquement une clé API d’essai pour vous. Cette clé API sera disponible sur le tableau de bord pour que vous puissiez la copier, ainsi que dans la section du tableau de bord intitulée « Clés API ».
Comment obtenir une clé API de production ?
Pour obtenir une clé de production, vous devez avoir des privilèges de propriétaire (ou demander au propriétaire de votre organisation d’effectuer les étapes suivantes). Accédez à la page Facturation et utilisation dans votre tableau de bord Cohere. Cliquez sur le bouton « Obtenir votre clé de production » et remplissez le formulaire « Passer à la production ».
Quelle est la différence entre une clé API d’essai et une clé API de production ?
Les appels API effectués à partir d’une clé API d’essai sont gratuits. Toutefois, les clés d’essai sont limitées en débit et ne peuvent être utilisées à des fins de production ou à des fins commerciales. Les appels API effectués à partir d’une clé API de production seront facturés sur la base d’un paiement à l’utilisation. Les clés API de production sont conçues pour une utilisation en production à grande échelle.
Existe-t-il des limitations de compte lors de l’inscription ?
Chaque compte commence comme un compte personnel et n’a accès qu’aux clés API d’essai. En tant que titulaire d’un compte personnel, vous ne pourrez pas ajouter d’autres membres tant que vous ne ferez pas partie d’une organisation.
Quelle est la différence entre un compte d’organisation et un compte personnel ?
Chez Cohere, une organisation est un groupe de comptes personnels qui partagent un portail de facturation unique. Les organisations ne reçoivent pas automatiquement l’accès à la clé API de production, et un membre de l’organisation doit toujours remplir notre formulaire de demande d’accès à la production. Les comptes personnels ne peuvent pas partager les informations de facturation avec d’autres comptes.
Quel modèle choisir ?
Le choix du modèle reflète la priorité que vous accordez aux performances et à la rapidité du modèle. Les grands modèles offrent de meilleures performances et sont capables d’effectuer des tâches plus complexes, tandis que les petits modèles ont des temps de réponse plus rapides.
Quand suis-je facturé ?
Les appels API effectués à partir d’une clé API d’essai sont gratuits. Les appels API effectués à partir d’une clé de production seront facturés sur la base d’un paiement à l’utilisation. Votre facture sera émise à la fin de chaque mois civil ou lorsque vous atteindrez 250 $ de solde impayé.
Le point d’accès que j’utilise est facturé par jeton. Qu’est-ce qu’un jeton ?
Les modèles linguistiques utilisent des « jetons » plutôt que des caractères ou des octets. Le nombre de jetons par mot dépend de la complexité du texte. Les textes simples peuvent se rapprocher d’un jeton par mot en moyenne, tandis que les textes complexes peuvent utiliser des mots moins courants qui nécessitent 3 à 4 jetons par mot en moyenne. Pour plus de détails sur les jetons, voir cette

Où puis-je trouver les prix de nos anciens modèles ?
Pour les clients existants :
Le prix pour Command est de 1,00 $/1M de jetons pour l’entrée et de 2,00 $/1M de jetons pour la sortie.
Le prix pour Command-light est de 0,30 $/1 million de jetons pour l’entrée et de 0,60 $/1 million de jetons pour la sortie.
Le prix pour Command R 03-2024 est de 0,50 $/1 million de jetons pour l’entrée et de 1,50 $/1 million de jetons pour la sortie.
Le prix pour Command R+ 04-2024 est de 3,00 $/1M de jetons pour l’entrée et de 15,00 $/1M de jetons pour la sortie.
Le prix pour Command R+ 08-2024 est de 2,50 $/1M de jetons pour l’entrée et de 10,00 $/1M de jetons pour la sortie.
Quel est le coût de l’accès aux modèles de recherche Aya via l’API ?
Les modèles Aya Expanse (8B et 32B) sur l’API sont facturés à 0,50 $/1M de jetons pour l’entrée et à 1,50 $/1M de jetons pour la sortie. Pour plus d’informations sur les modèles Aya, cliquez
ici
.
Comment Rerank définit-il une « recherche » dans sa tarification?
Une unité de recherche correspond à une requête comportant jusqu'à 100 documents à classer.
Si un document dépasse 500 jetons (y compris la longueur de la requête), il est automatiquement divisé en plusieurs segments. Chaque bloc est traité comme un document individuel et compte dans le nombre total de documents classés pour cette recherche.
Vous avez ainsi l’assurance d’une performance constante et d’une tarification précise lorsque vous travaillez avec des documents plus longs.
