모델 커스터마이제이션 및 프라이빗 배포 문의 방법은 어떻게 되나요?
Cohere는 기업 고객을 위해 맞춤형 모델 커스터마이제이션과 모든 제품의 프라이빗 배포를 지원합니다. 맞춤형 가격은 기업의 요구 사항에 따라 책정됩니다. 커스터마이제이션에 대한 자세한 내용은
여기
를, 프라이빗 배포에 대한 자세한 내용은
여기
를 참고하세요.
트라이얼 API 키는 어떻게 받나요?
계정을 생성하면 자동으로 트라이얼 API 키가 발급됩니다. 이 API 키는 대시보드에서 복사할 수 있으며, “API 키” 섹션에서도 확인할 수 있습니다.
프로덕션 API 키는 어떻게 받나요?
프로덕션 키를 받으려면 소유자 권한이 필요합니다(또는 조직의 소유자에게 다음 단계를 완료하도록 요청하세요). Cohere 대시보드의 청구 및 사용량 페이지로 이동하여 “프로덕션 키 받기” 버튼을 클릭하고 프로덕션 워크플로를 작성하세요.
트라이얼 API 키와 프로덕션 API 키의 차이점은 무엇인가요?
트라이얼 API 키를 사용한 API 호출은 무료입니다. 그러나 트라이얼 키는 속도 제한이 있으며 프로덕션이나 상업적 목적으로 사용될 수 없습니다. 프로덕션 API 키를 사용한 API 호출은 종량제 방식으로 요금이 부과됩니다. 프로덕션 API 키는 대규모 프로덕션 사용을 위해 설계되었습니다.
가입 시 계정에 제한 사항이 있나요?
모든 계정은 개인 계정으로 시작되며 트라이얼 API 키만 사용할 수 있습니다. 개인 계정에서는 조직에 속하지 않는 한 다른 멤버를 추가할 수 없습니다.
조직과 개인 계정의 차이점은 무엇인가요?
Cohere에서 조직은 단일 청구 포털을 공유하는 개인 계정의 그룹입니다. 조직은 자동으로 프로덕션 API 키 접근 권한을 부여받지 않으며, 조직의 멤버가 프로덕션 접근을 위해 신청서를 작성해야 합니다. 개인 계정은 다른 계정과 청구 정보를 공유할 수 없습니다.
어떤 모델을 선택해야 하나요?
모델 선택은 모델 성능과 속도에 대한 상대적인 우선순위에 따라 결정됩니다. 대형 모델은 더 나은 성능을 제공하고 더 복잡한 작업을 처리할 수 있지만, 소형 모델은 응답 속도가 더 빠릅니다.
청구서는 언제 발급되나요?
트라이얼 API 키를 사용한 API 호출은 무료입니다. 프로덕션 키를 사용한 API 호출은 종량제 방식으로 요금이 부과됩니다. 청구서는 매월 말 또는 미수금이 $250에 도달할 때 발급됩니다.
사용 중인 엔드포인트가 토큰 기준으로 청구됩니다. 토큰이란 무엇인가요?
언어 모델은 문자나 바이트가 아닌 “토큰”을 이해합니다. 단어당 토큰 수는 텍스트의 복잡성에 따라 달라집니다. 간단한 텍스트는 평균적으로 단어당 약 1개의 토큰을 사용하지만, 복잡한 텍스트는 덜 일반적인 단어를 사용해 평균적으로 단어당 3-4개의 토큰을 사용할 수 있습니다. 토큰에 대한 자세한 내용은
이 페이지
를 참조하세요.
레거시 모델의 가격은 어디서 확인할 수 있나요?
기존 고객을 위한 가격:
Command 가격은 입력 기준 $1.00/1M 토큰, 출력 기준 $2.00/1M 토큰입니다
Command-light 가격은 입력 기준 $0.30/1M 토큰, 출력 기준 $0.60/1M 토큰입니다
Command R 03-2024 가격은 입력 기준 $0.50/1M 토큰, 출력 기준 $1.50/1M 토큰입니다
Command R+ 04-2024 가격은 입력 기준 $3.00/1M 토큰, 출력 기준 $15.00/1M 토큰입니다
Command R+ 08-2024 가격은 입력 기준 $2.50/1M 토큰, 출력 기준 $10.00/1M 토큰입니다
API를 통해 연구용 Aya 모델에 접근하는 비용은 어떻게 되나요?
API를 통한 Aya Expanse 모델(8B 및 32B)의 비용은 입력 기준 $0.50/1M 토큰, 출력 기준 $1.50/1M 토큰입니다. Aya 모델에 대한 자세한 내용은
여기
를 참조하세요.
Rerank 가격 책정 시 “검색”은 어떻게 정의되나요?
단일 검색 단위는 최대 100개의 문서를 순위화하는 하나의 쿼리로 정의됩니다.
어떤 문서가 500 토큰(검색 쿼리 길이 포함)을 초과하면 자동으로 여러 청크로 분할됩니다. 각 청크는 개별 문서로 처리되어 해당 검색에서 순위화된 문서 총수에 포함됩니다.
이렇게 하면 긴 문서 작업 시 일관된 성능과 정확한 가격 책정이 보장됩니다.
