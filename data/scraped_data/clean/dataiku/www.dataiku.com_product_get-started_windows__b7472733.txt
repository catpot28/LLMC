Install Dataiku on Windows
Dataiku DSS wasn't originally designed to natively run on Windows. It is available as an experimental version and only for testing. Dataiku does not provide official support for this

installation. Follow the steps below to start using the Platform for AI success.
Dataiku DSS wasn’t originally designed to natively run on Windows. It is available as an experimental version and only for testing. Dataiku does not provide official support for this installation. For more information check the
installation on Windows documentation
.
The Dataiku Launcher application for Windows will assist you in installing and updating to the latest versions of Dataiku DSS as soon as they get released. You only need to download it once.
1. Installing the launcher
Download for Windows
Double click on the setup file to install the launcher.
2. Starting the launcher
You can start the Dataiku Launcher application from either the start menu or the shortcut on your Windows desktop.
When opening the launcher for the first time, it will guide you through the install of Dataiku DSS.
If this is not already the case the launcher will ask you if you want to enable long path support on your machine (recommended).
Once the installation is over, Dataiku DSS opens automatically in a browser tab (Chrome and Firefox are supported). If you close the tab and want to reopen Dataiku DSS, double click on the bird icon in the tray (notification area) or right click on it and select “Open Dataiku DSS”, or open a new tab and browse to http://localhost:11200.
