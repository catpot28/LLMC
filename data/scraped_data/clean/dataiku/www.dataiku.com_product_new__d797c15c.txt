What’s new in Dataiku
Accelerate adoption of agentic AI and trusted analytics by meeting users where they work, connecting agents to enterprise knowledge sources, and more in Dataiku 14.6.
Request a demo
Start trial

Bring agent building to everyone
Agent Hub’s Quick Agents let any business user build a working agent in minutes by combining prompts, tools, and enterprise data — no code required.
With a new direct SharePoint integration, those agents draw from real enterprise knowledge instead of stale uploads, so users get answers they can act on with confidence.
Explore agent hub

Ensure continuous agent quality
Design agentic systems with predictable behavior and ensure their quality over time.
Structured Visual Agents let teams compose agents visually using ordered blocks and logical branches, including reflection steps, agent handovers, and human approvals.
Agent Review then replaces one-off validation with continuous quality assurance, enabling AI builders and SMEs to jointly define standards, build repeatable tests, and validate agent behavior over time, with optional SME grading.
Read the documentation

Ground agents in business context
Give your agents the business context they need to answer accurately.
Flexibly build semantic models in Dataiku, or import them from Snowflake Semantic Views (new in 14.6), then refine them with the key metrics, table relationships, and glossary terms specific to your use case before testing and connecting them to your agents of choice.

Orchestrate your entire AI ecosystem from one platform
Manage and compose agents across internal assets and third-party platforms like Snowflake Cortex, Databricks, Google Vertex AI, and AWS Bedrock.
External agents become first-class, governed Dataiku agents with centralized testing, monitoring, and orchestration.

Embed trusted agents where business users work
Bridge the gap between technical development and real-world adoption.
Deploy approved agents directly into Slack or Microsoft Teams, allowing business users to discover and interact with AI agents safely within their existing workflows.

Enhance AI coding experience
Build and debug AI systems faster with improvements to Code Studio.
Developers can now debug managed webapps with breakpoints, test and version code agents more easily, and leverage AI coding assistants like Claude Code.

Bring AI impact to all processes
Move from concept to impact with fully packaged applications dedicated to your business teams.
Turn trusted knowledge into high-quality, reliable answers to any questionnaire-based activity in a fraction of the time with the RFx Accelerator.
Spot bottlenecks, compliance gaps, and other slowdowns faster with Process Mining, which turns your raw process logs into clear, actionable insights.
