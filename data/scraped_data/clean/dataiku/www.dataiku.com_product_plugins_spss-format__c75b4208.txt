IBM SPSS Format Reader

IBM SPSS Format Reader

This plugin provides a format to import SAV files into DSS using Dataiku's SPSS Format reader

IBM SPSS is a famous software package used for statistical analysis.

This plugin provides a custom format reader to import the contents of a .sav data file into your DSS project.

Import your SPSS data directly in DSS.

How To Use

You need to import your .sav file into DSS and then choose the SPSS format, as shown in the picture above.

This format supports the following records types from .sav files :

Numeric, string, and long string
records.

Date
records, which are deliberately not kept in their original SPSS date display format, but instead converted to the more practical and less ambiguous ISO 8601 format (yyyy-mm-dd).

Variable labels
which can be used as column names.

Value labels
which can be used as column values.

Image Copyright IBM

Install In DSS

To install the plugin, open the
Apps menu, click Plugins and search for IBM SPSS Format Reader.

Alternatively, you can download a zipped version
here
.
