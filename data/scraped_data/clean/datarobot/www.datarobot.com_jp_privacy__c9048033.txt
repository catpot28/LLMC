本ポリシーは、当社とリンクしている第三者の Web サイト、アプリケーション、ビジネスには適用されません。これらをご利用の際は、ご利用先のプライバシーポリシーをお読みになり、お客様の個人データの収集および使用方法についてご確認ください。

お客様の個人データの使用方法およびその処理の法的根拠

当社がお客様の個人データを使用する方法は、お客様による当社のご利用方法によって異なります。当社が収集するお客様の個人データの具体的な使用目的は以下のとおりです。EU 一般データ保護規則（以下「
GDPR
」）または英国一般データ保護規則（以下「
UK GDPR

ソリューションおよび Web サイトを提供およびサポートするため。
当社は、当社のソリューションおよび Web サイトを提供およびサポートするため、お客様の個人データを使用します。そのような提供およびサポートの一環として、ソリューションまたは電子メールを通じて、お客様のアカウントや当社との取引に関するお知らせ、技術的な通知、セキュリティアラート、請求、サポート関連のメッセージをお送りすることがあります。これらのメッセージはソリューションの一部とみなされるため、オプトアウトすることはできません。
処理の法的根拠:
当社は、お客様またはお客様の勤務先に対して、ソリューションへのアクセスおよびそのサポートを提供する契約上の義務を負っている場合があり、その場合、お客様の個人的な連絡先データの処理が必要になります。それ以外の場合は、当社は、Web サイトへのアクセスおよびそのサポートをお客様に提供することに正当な利益を有しています。

ソリューションおよび Web サイト上でパーソナライズされたエクスペリエンスを提供するため。
当社のソリューションおよび Web サイトのコンテンツやエクスペリエンスをパーソナライズすること、お客様の関心事をより深く理解し、お客様の関心事に基づいてパーソナライズされたお勧め情報を提供すること、および当社でのエクスペリエンスをお客様の好みに合わせてカスタマイズすることを目的に、収集した情報を使用します。
処理の法的根拠:
当社は、お客様の個人データを処理し、当社でのお客様のエクスペリエンスを改善することに正当な利益を有しています。

お客様との関係性を把握および管理するため。
当社は、ソリューションおよび Web サイトの利用状況を把握することによって、お客様と当社間における関係の健全性をモニタリングできるようにするため、また、当社のエンタープライズユーザーについては、利用動向を明らかにするとともに、ソリューションの利用状況に基づき、新しいサービスまたは機能を提案するため、お客様の個人データを利用します。また、お客様の会社が当社のソリューションを最大限に活用できるようにするため、このデータはエンタープライズ顧客にも提供されます。
処理の法的根拠
: 当社は、お客様がソリューションおよび Web サイトの利用から最大限の価値を得られるようにすること、製品の支持者を特定すること、ならびにお客様の利用またはサブスクリプションを最適化するための提案を行うことに正当な利益を有しています。

お客様からのご質問、ご意見、ご感想にお応えするために、電子メールまたはその他の方法でお客様にご連絡します。例えば当社のコミュニティボードでのコメントに応対し、Web サイトから投稿された質問に回答します。また、お客様のエクスペリエンスまたはバックグラウンドから、当社のソリューションが特にお客様の関心を引くものであろうと当社が判断した場合は、電子メール、電話またはソーシャルメディアを介し、パーソナライズしたメッセージによってお客様に連絡することがあります。また、お客様は、新しい製品の機能やサービスに関する電子メールを受け取るため、オプトインすることもできます。これらの連絡は、メッセージに記載されているオプトアウト手順に従うか、下記のお問い合わせ先からご連絡いただくことで、いつでもオプトアウトできます。

製品開発で利用する匿名データを作成するため。
当社は、個人データを含むデータから個人を特定できないようにするため、これらのデータから個人識別子を除去することがあり、また、複数のソースおよび／または個人からのデータと組み合わせることによって、これらのデータを集計することがあります。当社は、これらのデータを利用することによって、機能の選択および機能のギャップを把握し、製品の価値の低下を判断し、および製品開発に関する意思決定を行うことがあります。収集されたデータを製品開発に利用する場合は、すべての個人データおよび顧客情報を必ず除去します。
処理の法的根拠:
当社は、ソリューションを改善するために使用するため、匿名データを作成する正当な利益を有しています。

セキュリティ、コンプライアンス、不正防止、安全確保のため。
