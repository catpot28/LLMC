How many agents can I create?
There is no limit to the number of agents you can create on any plan. You are only limited by the number of concurrent calls
available on your plan

monthly credit limit

What LLMs can I use with my AI agents?
You can select from the leading Claude, GPT, and Gemini models or you can connect a custom LLM with a server integration.
Can my agent make API calls to external services?
Yes, with “Tools” you can make webhook requests to external services to get real-time data or take actions. ElevenAgents also supports connecting to MCP servers.
How can I make and receive phone calls with ElevenAgents?
Integrate with Twilio, Genesys, Vonage, Telynx, Plivo or connect to any SIP compatible PBX or telephony system.
