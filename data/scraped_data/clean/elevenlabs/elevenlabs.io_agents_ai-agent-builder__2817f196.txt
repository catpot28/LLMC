Frequently asked questions
What is an AI agent builder?
An AI agent builder is a platform that lets you design, test, and deploy conversational agents. Combining a visual workflow designer, LLM configuration, voice and channel settings, and integration tools into a single interface. ElevenAgents is a voice-first AI-powered agent builder that covers everything from prototype to production.
Do I need coding experience to build an agent?
No. The visual workflow builder lets you script conversations, define decision trees, and configure guardrails without writing code. For advanced use cases, developers can extend agents using our Python and JavaScript SDKs, trigger tool calls, and orchestrate multi-agent handoffs programmatically.
What channels can I deploy agents to?
Agents built with ElevenAgents deploy across phone lines, web widgets, mobile apps, WhatsApp, and embedded systems. Telephony (SIP/Twilio), WebRTC, and native messaging integrations are all supported from the same agent configuration.
Which LLMs and integrations are supported?
ElevenAgents is LLM-agnostic. Use ElevenLabs-hosted models or bring your own from OpenAI, Anthropic, Google, or any custom provider. On the integration side, you can connect to Salesforce, HubSpot, Zendesk, ServiceNow, Twilio, Vonage, Genesys, and any API via MCP.
How does the knowledge base and RAG work?
Upload internal documents, policies, or product data to your agent's knowledge base. The agent uses retrieval-augmented generation (RAG) to ground responses in your content. Reducing hallucinations and keeping answers accurate and on-brand.
What compliance certifications does ElevenAgents hold?
ElevenAgents is SOC 2 Type II, ISO/IEC 27001, PCI DSS Level 1, HIPAA, GDPR, and TXRAMP Level 2 certified, among others. Zero retention mode, VPC deployment, end-to-end encryption, and regional data residency (US, EU, India) are all available. See the full list at elevenlabs.io/compliance.
