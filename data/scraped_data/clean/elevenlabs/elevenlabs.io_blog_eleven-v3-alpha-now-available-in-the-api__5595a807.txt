Eleven v3 is no longer in alpha, and is now generally available.
Today, we’re making Eleven v3 (alpha) available in our API.
Eleven v3 (alpha) introduces a new level of expressiveness, control, and multilingual support for building voice-first applications.
Dialogue mode with unlimited speakers
Support for more than 70 languages
Enhanced voice and emotional control using audio tags
These features enable developers to create lifelike, emotionally rich speech experiences for any use case. With dialogue mode, Eleven v3 (alpha) can generate realistic multi-speaker conversations that handle interruptions, shifts in tone, and emotional cues based on context.
If you’re building in media & entertainment, on videos, video games, audiobooks, or media tools - this unlocks a new level of expressiveness.
Already powering industry leaders
Over the past weeks, we partnered with leading companies, like HeyGen, Poe (by Quora), Captions and InVideo to integrate Eleven v3 (alpha) into their products.
