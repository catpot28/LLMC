Frequently asked questions
What is ElevenCreative Flows?
Flows is a node-based creative canvas inside ElevenCreative. It connects image generation, video, Text to Speech, lip-sync, sound effects and music into a single visual workspace. With Flows you can map out your creative pipeline, chain models together and run it all from one place.
What can I build with ElevenCreative Flows?
Flows supports any multi-step creative pipeline. Common use cases include ad creative production, product imagery with voiceover, content localization across languages, podcast and audiobook production, and AI filmmaking. Each Flow is reusable. Build once, then run it with different inputs.
What models are available in ElevenCreative Flows?
Flows integrates image and video models - including Veo, Sora, Kling, Wan, Flux, Seedance and more - alongside the full ElevenLabs audio stack: Text to Speech (including v3), voice cloning, lip-sync, sound effects and music generation.
Can I edit one step without regenerating everything?
Yes. Flows supports non-destructive iteration. You can re-run a single node and only downstream nodes connected to that path will need to be updated. Unconnected branches remain unchanged.
How much does ElevenCreative Flows cost?
Flows is available on all paid plans. Each node generation costs credits based on the model and settings used, identical to standalone tool pricing. Re-running a node triggers a new generation and a new credit charge. See the pricing page for details.
Is API access available for ElevenCreative Flows?
Programmatic execution via API is planned for a future release. This will enable mass creative production use cases, such as connecting a CMS to a Flow for automated content generation. Enterprise customers interested in early access should contact their account team.
How is Flows different from Studio?
Studio uses a linear timeline for precise frame-by-frame editing with tracks for video, audio, music and captions. Flows uses a node-based canvas for building multi-step generative pipelines. Use Flows to orchestrate complex generation chains, then export to Studio for final editing.
Can I share or reuse a Flow?
Yes. Each Flow is automatically saved as a project. You can reload a Flow, modify prompts or settings and re-execute to create variations without rebuilding the entire pipeline. You can also browse and duplicate Flows built by other creators.
