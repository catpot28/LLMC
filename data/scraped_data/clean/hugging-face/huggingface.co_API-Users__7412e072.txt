Troubleshooting:

Q1. What is this group about? ||
A1. This group is for all API (endpoint) users, a way to connect and to find information.

Q2. Where to report problems when a certain model/API/space is down? ||
A2. First validated the problem is not located with you or your code; make a 'New Discussion' in the 'Community'-tab the model/API page. Mostlikely the code is outdated or the owner recently changed some code.

Q3. Where to report problems when HuggingFace or all models/APIs/spaces are down or corrupted (giving errors)? ||
A3. After validated the problem is not located with you or your code, the fasted way is to report the problem on the Hugging Face DISCORD, you can use the #general channel for this. You best mention the admin tag in your post.

Q4. Where can I find more information about different API providers? ||
A4.
https://huggingface.co/blog/inference-providers
