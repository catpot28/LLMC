NVIDIA AI Enterprise is an end-to-end, cloud-native software platform that accelerates data science pipelines while streamlining development and deployment of production-grade retrieval-augmented generation (RAG), agents, and other enterprise generative AI applications. Easy-to-use NVIDIA NIM™ inference microservices provide optimized model performance with enterprise-grade security, support, manageability, and stability.

Acceleration Out of the Box

NVIDIA H200 and H100 Tensor Core GPUs

NVIDIA H200 NVL, H100 NVL, and H100 PCIe GPUs for mainstream servers include NVIDIA AI Enterprise software to help users accelerate AI workloads, such as generative AI and large language model (LLM) inference. This software is included as a part of a five-year NVIDIA Enterprise subscription that comes with these GPUs.

The NVIDIA A800 40GB Active GPU includes NVIDIA AI Enterprise software to help users tackle demanding AI, data science, and analytics workflows on workstations. This software is included as a part of a three-year NVIDIA Enterprise subscription that comes with this GPU.

FAQ

Which NVIDIA GPUs include NVIDIA Enterprise subscriptions?

Each NVIDIA H200 NVL, H100 PCIe, and H100 NVL GPU comes with a five-year NVIDIA Enterprise subscription, which includes NVIDIA AI Enterprise. Software activation is required.

Each NVIDIA A800 40GB Active GPU comes with a three-year NVIDIA Enterprise subscription, which includes NVIDIA AI Enterprise. Software activation is required.

How do I activate NVIDIA AI Enterprise?

The NVIDIA Enterprise software entitlements that come with select NVIDIA GPUs require self-registered activation. You'll need the serial numbers of your NVIDIA GPUs to start the process. View instructions above to complete the activation.
