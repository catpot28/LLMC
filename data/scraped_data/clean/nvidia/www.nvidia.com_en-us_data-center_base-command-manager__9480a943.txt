Overview

Cluster Management for High-Performance Computing and AI

NVIDIA Base Command Manager is the standard for provisioning, managing, and monitoring
high-performance computing (HPC)
and AI clusters at scale, with over a decade of proven performance behind it. It manages and automates end-to-end operations for mixed, hardware-agnostic environments — from a few nodes to hundreds of thousands — across edge, data center, and multi- or hybrid-cloud deployments. With reliable core capabilities, release predictability, support for
NVIDIA Blackwell
and
NVIDIA Rubin architectures
, and multiple user interface options, Base Command Manager is the foundation teams rely on to maximize infrastructure utilization so workloads run with consistent, high throughput.

Build and Manage Clusters

Manage your entire cluster—from AI and analytics applications to traditional HPC, from bare metal to containers, and from the edge to on premises to the public and hybrid clouds.

Comprehensive Cluster Management

Base Command Manager offers fast deployment and end-to-end management.

Auto-Scale Capacity

Dynamically power cluster nodes up and down and repurpose capacity on-demand, keeping cluster utilization efficient.

Hardware Agnostic

Base Command Manager manages nearly any CPU or GPU-accelerated cluster with broad hardware support designed for modern, heterogeneous data centers.

New Releases

Base Command Manager 11

NVIDIA Base Command Manager 11 is fully integrated across the NVIDIA ecosystem with support for NVIDIA’s latest architectures. It features an improved user interface for Base View that gives administrators greater flexibility when performing cluster operations. In addition to the cleaner and easier-to-use design, Base View now offers new installation wizards, monitoring dashboards, and improved scalability. Base Command Manager 11 also enables easier in-place updates for Slurm, introduces new JupyterLab integration, and expands the Cluster on Demand ecosystem.

Base Command Manager offers Base View interface for performing day-to-day operations. It allows administrators to quickly view the utilization and health status of their clusters and perform a number of tasks through a graphical user interface.

Benefits

Quickly Build and Manage Clusters of Nearly Any Size

Easily Provision and Automate

Streamline cluster provisioning and automation, from single nodes to thousands, with full support for NVIDIA GPU-accelerated and other accelerated systems, as well as Arm® and x86-based CPU nodes, all under a single management platform.

Monitor Utilization and More

Optimize cluster resources with pre-built, customizable dashboards and real-time health monitoring that give administrators clear visibility into trends to improve cluster utilization and accelerate data center ROI.

Flexible User Interface

Base Command Manager includes BaseView, an intuitive web interface for day-to-day cluster operations, with the same capabilities also accessible via full command-line and API options for automation and integration.

Management Software That Is Proven

With thousands of deployments, including on NVIDIA DGX™ systems, Base Command Manager is a reliable and proven solution for HPC and AI clusters, offering release predictability where features are continuously updated, tested, and fine-tuned.
