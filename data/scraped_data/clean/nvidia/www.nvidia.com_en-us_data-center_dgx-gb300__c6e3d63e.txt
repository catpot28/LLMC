Overview

AI Factory Infrastructure, the NVIDIA Way

NVIDIA DGX™ GB300 is the highest-performing, largest-scale AI system available for enterprises. Built with
NVIDIA Grace™ Blackwell Ultra Superchips
and scalable up to thousands, DGX GB300 is a rack-scale, liquid-cooled system designed to fit into modern data centers using
NVIDIA MGX™
racks. With DGX GB300, the world’s leading enterprises can break through performance bottlenecks and equip their organization with an infrastructure solution capable of solving any problem.

Features

Democratizing Hyperscaler AI

Built on NVIDIA Grace Blackwell Ultra Superchips

Powered by
Grace Blackwell Ultra Superchips
, NVIDIA DGX GB300 is designed to maximize performance for training, post-training, and test-time inference, boosting dense FP4 performance by 1.5x and attention performance by 2x over
NVIDIA DGX GB200
.

World-Class Infrastructure Resiliency

NVIDIA Mission Control
streamlines AI operations, from workloads to infrastructure, with world-class expertise delivered as software. Powering NVIDIA Blackwell data centers, Mission Control provides full-stack intelligence for infrastructure resilience, enabling every enterprise to run AI factories with hyperscale efficiency.

Designed for Modern Data Centers

NVIDIA DGX SuperPOD™ with DGX GB300 systems eliminates the guesswork from deploying large-scale AI infrastructure with a simple, easy-to-deploy rack architecture designed to take advantage of the latest advancements in data center engineering.

NVIDIA DGX GB300 Specifications

GPU

72x NVIDIA Blackwell Ultra GPUs, 36x NVIDIA Grace CPUs

CPU Cores

2,592 Arm Neoverse V2 cores

GPU Memory | Bandwidth

20 TB | Up to 576 TB/s

Total Fast Memory

37 TB

Performance

FP4 Tensor Core: 1440 PFLOPS | 1080 PFLOPS*
FP8/FP6 Tensor Core: 720 PFLOPS**

Networking

72x OSFP single-port NVIDIA® ConnectX®-8 VPI with 800 Gb/s NVIDIA InfiniBand

18x dual-port NVIDIA® BlueField®-3 VPI with 200 Gb/s NVIDIA InfiniBand and Ethernet

NVIDIA NVLink Switch System

9x L1 NVIDIA NVLink™ Switches

Management Network

Host baseboard management controller (BMC) with RJ45

Software

NVIDIA Mission Control
NVIDIA AI Enterprise
NVIDIA DGX OS / Ubuntu

Enterprise Support

Three-year business-standard hardware and software support

**Without sparsity.
