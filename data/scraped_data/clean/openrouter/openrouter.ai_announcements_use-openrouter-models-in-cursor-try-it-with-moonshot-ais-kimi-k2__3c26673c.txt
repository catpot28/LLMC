Use OpenRouter Models in Cursor: Try it with Moonshot AI's Kimi K2
If you're using
Cursor
as your AI coding assistant, you can now connect it to OpenRouter to access models like Kimi K2 by Moonshot AI, which is now live on the platform.

Kimi K2 delivers
1 trillion parameters
, a
65.8% SWE-Bench Verified score
, and leads the open-source charts for code generation and tool use. It is fully accessible in Cursor with just a few configuration steps.

⚙️ How to Use OpenRouter in Cursor

Open Cursor, go to:

Settings → Cursor Settings → Models

Scroll down to
API Keys
and do the following:

Turn on
OpenAI API Key

Paste in your
OpenRouter API key

Enable
Override OpenAI Base URL

Set it to:
https://openrouter.ai/api/v1

Scroll up to
"Add or search model"
and enter:
moonshotai/kimi-k2

Add it, toggle it on, and you're set.

Now go to the chat pane in Cursor and choose
Kimi K2
from the model dropdown.

⚠️ Heads up: Cursor may warn that the model has limited agentic support. You can safely ignore this — Kimi K2 is fully capable in assistant-style workflows.
