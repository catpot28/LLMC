Feature Request

Add Google Maps Connector to Perplexity AI

Problem Statement

Perplexity AI currently lacks direct access to Google Maps data, which limits its ability to provide accurate, real-time, and location-aware answers for queries involving places, routes, distances, opening hours, reviews, and local businesses. Users must manually cross-check results with Google Maps, breaking workflow efficiency and increasing friction.

Proposed Solution

Introduce a
Google Maps connector
that allows Perplexity AI to query Maps data when relevant.

The connector should enable Perplexity to:

Retrieve place details (addresses, hours, ratings, reviews)

Answer location-based questions (e.g., “best cafés near me”)

Estimate distances and travel times

Support route and proximity-based reasoning

Example use case:

A user asks,
“Find a highly rated Italian restaurant within 10 minutes walking distance from Times Square that’s open now.”

With the Google Maps connector, Perplexity could return an accurate, up-to-date answer grounded in real Maps data.

API Impact

Affected API component:
Search / Retrieval

Related to a specific model:
Potentially useful for advanced reasoning models (e.g., Deep Research)

API changes required:

New external connector integration

Optional parameters for location context (latitude/longitude, radius, travel mode)

Permission-based access to Maps data where applicable

Alternatives Considered

Manual copy-pasting from Google Maps

Using generic web search results for location data

These approaches are insufficient because they are slower, less accurate, and do not support real-time or proximity-based reasoning.

Additional Context

Google Maps is the most widely used and trusted source for location data

A native connector would significantly improve Perplexity’s usefulness for travel, local discovery, logistics, and business research

Similar integrations already exist in other AI tools, indicating strong user demand
