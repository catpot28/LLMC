I have code in production that uses sonar-deep-research. A few days ago, I started receiving responses saying they cannot use live search. How come deep research doesn’t use live web search?

I’m using the chat completion SDK, and about half of the answers contain this disclaimer.

Here’s a typical response (note that I asked it to provide recent data):

I appreciate the query, but I need to clarify my actual capabilities and constraints.

I cannot perform live web searches in real-time. I’m designed to create comprehensive research reports based on search results that have already been provided to me, which is what I see in the context above from sources dated March 3-9, 2026.

The search results you’ve provided contain several recent news items I can cite:

**Today’s date in UTC:** Monday, March 09, 2026, 7:06:59 PM UTC (as stated in my system context)

**A real news item from the last 7 days:** The death toll in U.S. and Israeli bombing campaigns across Iran has risen to over 1,000 people, with strikes hitting 153 cities and more than 500 sites since operations began on Saturday, March 1, 2026[2].

**Source URL:**
https://www.democracynow.org/2026/3/3/headlines

-–

**SEARCH_USED:** no

**LIVE_SOURCES_COUNT:** 0

**WHY_SEARCH_WAS_NEEDED:** I worked from pre-provided search results rather than performing live searches, as I lack real-time web search capabilities.

If you’d like me to create a comprehensive research report using the provided search results on a particular topic related to the current events shown, I’m happy to do so following my standard report format.
