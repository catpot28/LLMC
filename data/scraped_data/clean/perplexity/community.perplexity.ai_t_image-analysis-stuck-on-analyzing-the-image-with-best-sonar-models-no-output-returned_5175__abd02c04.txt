Bug Description

When uploading an image and selecting “Best” or “Sonar” model, the response gets stuck on the status message “Analisando a imagem para identificar o que está visível” (“Analyzing the image to identify what’s visible”) and never returns a final answer. The UI shows “1 fonte” (1 source) but no output is generated.

Steps to Reproduce

Open a new thread on Perplexity (web)

Select “Best” or “Sonar” as the model

Upload any image

Send a prompt like “analyze this image”

The response indicator hangs indefinitely on the analysis status

Expected Behavior

The model should return an analysis of the uploaded image.

Actual Behavior

Response never completes. No error message shown, no output generated, just the loading status message stuck.

Environment

Platform: Desktop App

Plan: Pro

Model: Best / Sonar

OS: macOS Tahoe 26.5

Additional Notes

Does not happen with other models like GPT/Claude/Gemini on Perplexity).

Reproducible consistently / intermittent
