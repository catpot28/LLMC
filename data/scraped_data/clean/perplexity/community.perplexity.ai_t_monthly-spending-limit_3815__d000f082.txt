Feature Request

A monthly spending limit feature for the API keys

Problem Statement

Currently the only options for spending are to prepurchase tokens, or enable auto tops ups. There is no limit to the topups so spending is unlimited with that turned on.

Proposed Solution

Either have a setting for the max number of top ups in a month or max dollars spent for the month. After reaching this value the system doesn’t auto reload.

API Impact

Which API component is affected?
Billing

Is this related to a specific model?
No

Would this require new API parameters or changes to existing ones? New

Alternatives Considered

The workaround is to buy a lot of tokens up front but that is not economical if you don’t know in advance how much you may spend in the coming month.
