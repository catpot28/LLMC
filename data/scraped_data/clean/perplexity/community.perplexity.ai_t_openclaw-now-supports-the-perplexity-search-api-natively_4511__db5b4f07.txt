Hey all! OpenClaw’s web search provider now supports Perplexity’s Search API as a first-class option that gives back raw ranked results (title, URL, snippet). You can now give your Claw up-to-date information from the best search API around.

Perplexity recently shipped better snippet extraction too
: smaller, more relevant snippets per result, which means lower token costs and cleaner context for your downstream LLM!
