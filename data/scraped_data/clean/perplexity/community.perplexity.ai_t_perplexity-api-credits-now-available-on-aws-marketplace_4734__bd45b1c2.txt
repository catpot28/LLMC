Perplexity API credits are now available on

Enterprise customers can purchase API credits directly through their AWS account. Credits are applied to your Perplexity API balance and work across all APIs.

Purchasing credits through AWS Marketplace consolidates billing on your existing AWS invoice with no separate vendor contract.
