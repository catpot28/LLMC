Describe the Bug

I purchased API credits twice, but my credit balance never updated and continues to show
$0
, making my account unusable.

I initially purchased
$26 in API credits
. After waiting several minutes, my balance still showed $0. Assuming this might be a transient issue, I made a second purchase of
$25
, but the balance still did not update.

At this point, the account cannot be used despite successful payments, which appears to be a billing or credit application bug.

Expected Behavior

After a successful purchase, the API credit balance should update immediately (or within a reasonable processing window) and allow API usage.

Actual Behavior

Payments were successfully processed. (See screenshot)

API credit balance remains at
$0
(See screenshot)

Account is unusable and cannot consume API credits (See screenshot)

Also note that credits were purchased on 13th December, but no credits are available to use the API since 12th December

Steps to Reproduce

Log in to the Perplexity API dashboard

Purchase $26 in API credits via
https://www.perplexity.ai/account/api/billing

Wait several minutes and refresh the dashboard

Observe that the credit balance remains $0

Purchase an additional $25 in API credits

Refresh the dashboard again

Observe that the credit balance still remains $0 and API usage is blocked
