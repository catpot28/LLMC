Feature Request: Perplexity Code Agent with IDE Integration

Perplexity Computer has unique advantages that no current coding tool offers — real-time web search, 400+ service connectors, and multi-model orchestration. These could be game-changing inside an IDE.

Proposed capabilities:

Inline diff review with approve/reject flow (like Claude Code / Gemini Code Assist)

Agentic code development — plan, execute, and refactor across files

Live documentation lookup and web search without leaving the editor

Pull context from connected services (Confluence pages, Jira tickets, GitHub issues, Slack threads) directly into the coding workflow

Plugin support for JetBrains (IntelliJ, WebStorm) and VS Code

Scheduled code tasks (e.g., dependency vulnerability checks, automated PR creation)

Why this matters:

Current tools like Claude Code, GitHub Copilot, and Gemini Code Assist lack Perplexity’s research depth and service integrations. Combining Perplexity’s orchestration strengths with a tight IDE loop would be a significant differentiator.
