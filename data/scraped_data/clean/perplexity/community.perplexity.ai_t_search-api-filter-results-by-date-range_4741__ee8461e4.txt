Search API — Filter Results by Date Range

Announcements

Kesku

October 29, 2025, 5:00pm

1

New in the Perplexity Search API — developers can now filter search results by specific time periods or recency.

Perfect for getting only the most recent results or narrowing to a specific date window.

img_date_filter.jpg
1166×832 66.6 KB

# Simple recency filter
search = client.search.create(
query="AI safety research",
search_recency_filter="month"
)

# Precise date range
search = client.search.create(
query="AI safety research",
search_after_date_filter="01/01/2025",
search_before_date_filter="06/30/2025"
)

Available recency values:
hour

day
,
week
,
month
,
