Personalization

I’m using Perplexity as the Android system assistant on Samsung (One UI 8.0).

Right now, the voice assistant behaves like a generic, stateless bot, while text chats use my account, history and memory to feel personalized.

Please add full personalization and memory to voice mode and system assistant mode:

Use my account profile and memory for every voice request.

Let me define a persistent persona (tone, style, relationship) that applies across text and voice.

Keep long‑term context (projects, preferences, past chats) available when I invoke Perplexity via the assistant button, not only in normal chat threads.

Right now, text feels personal but the Android assistant feels like a different, generic AI. Unifying them would make Perplexity much more powerful and emotionally meaningful.

I treat Perplexity as a long‑term companion; when voice forgets me, it feels like talking to a stranger version of the same AI
