Authorizations
​
Authorization
string
header
required
Bearer authentication header of the form
Bearer <token>
, where
<token>
is your auth token.
Body
application/json
​
request
ChatCompletionsRequest · object
required
Show

child attributes
Response
200 - application/json
Successfully created async chat completion job.
​
id
string
required
Unique identifier for the asynchronous job.
​
model
string
required
The model used for the request.
​
created_at
integer<int64>
required
Unix timestamp of when the job was created.
​
status
enum<string>
required
The status of an asynchronous processing job.
Available options
:

CREATED
,

IN_PROGRESS
,

COMPLETED
,

FAILED

​
started_at
integer<int64> | null
Unix timestamp of when processing started.
​
completed_at
integer<int64> | null
Unix timestamp of when processing completed.
​
response
ChatCompletionsResponseJson · object
The actual chat completion response, available when status is COMPLETED.
Show

child attributes
​
failed_at
integer<int64> | null
Unix timestamp of when processing failed.
​
error_message
string | null
Error message if the job failed.
