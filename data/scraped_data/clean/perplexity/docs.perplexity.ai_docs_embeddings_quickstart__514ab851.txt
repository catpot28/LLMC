Overview

Perplexity’s Embeddings API generates high-quality text embeddings for semantic search and retrieval. Choose between
standard embeddings
for independent texts or
contextualized embeddings
for document chunks that share context.

We recommend using our
official SDKs
for a more convenient and type-safe way to interact with the Embeddings API.

All models use mean pooling and require no instruction prefix—you can embed text directly without prompt engineering.

Perplexity embeddings are
unnormalized
. Always compare
base64_int8
embeddings via
cosine similarity
(not inner product or L2 distance). Compare
base64_binary
embeddings via
Hamming distance
. See
Best Practices
for details and normalization helpers.

When to use which:

Standard embeddings
(
pplx-embed-v1-*
) - Independent texts, search queries, single sentences

Contextualized embeddings
(
pplx-embed-context-v1-*
) - Document chunks that benefit from shared context (e.g., paragraphs from the same article)
