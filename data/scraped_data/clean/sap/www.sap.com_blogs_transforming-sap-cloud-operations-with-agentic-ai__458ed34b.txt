Transforming SAP cloud operations with agentic AI: How SAP and AWS are innovating together

Proactively manage complex cloud landscapes by integrating intelligent, real-time insights directly into operational workflows.

SAP Administrators today manage complex, multi-account Amazon Web Services (AWS) landscapes where querying resources, retrieving the right guidance, and making informed decisions quickly can mean the difference between seamless operations and costly downtime. AWS and SAP are collaborating to change that — bringing artificial intelligence and machine learning (AI/ML) directly into the operational fabric of SAP environments running on AWS.

Together, AWS and SAP are co-developing AI-powered capabilities purpose-built for SAP workloads on AWS. This collaboration focuses on a shared goal: helping customers prevent business-impacting incidents before they occur, rather than scrambling to resolve them after the fact.

Introducing the AWS Operator Companion Agent

At the heart of this joint innovation is an AI-driven troubleshooting agent designed for SAP Day 2 operations. SAP's Global Cloud Operations (GCO) team has integrated Model Context Protocol (MCP) servers into the GCO Agentic AI Hub, enabling a new class of intelligent, context-aware agents that interact directly with external systems and documentation. The first proof-of-concept implementation of this capability is the AWS Operator Companion Agent — a purpose-built AI assistant that connects the GCO Agentic AI Hub to AWS through the Agent-to-Agent (A2A) Protocol.

This means SAP Administrators can now query AWS resources, retrieve operational guidance, and make faster decisions with reduced cognitive load — all through a single conversational interface within the Hub. The agent combines real-time AWS insights with relevant internal documentation, eliminating the need to context-switch across multiple tools and consoles. AI-powered troubleshooting for SAP operations — purpose-built agents that understand the intersection of SAP application behavior and AWS infrastructure, providing contextual recommendations that account for both layers simultaneously.

This initiative is a fundamental shift in how cloud operations are managed. We are transforming the role of the SAP Administrator from a reactive troubleshooter into a proactive, strategic operator. By providing AI-powered, contextual insights at their fingertips, we're reducing cognitive load and enabling faster, smarter decisions that keep businesses running smoothly.

Lalit Patil, Chief Technology Officer, SAP Global Cloud Operations

How it works

The architecture is straightforward. A user submits a query to the GCO Agentic AI Hub, which orchestrates the interaction through the A2A Protocol to the AWS Agent. The AWS Agent processes the request, retrieves the relevant information, and returns a response back through the Hub to the operator. This design keeps the Hub as the central orchestration layer while enabling direct, secure interaction with AWS services — supporting the complex, multi-account AWS landscapes that enterprise SAP customers operate across.

What this means for customers

Early results from the proof of concept show strong potential to streamline operations for SAP customers running on AWS. SAP Administrators spend less time navigating between systems and more time making decisions that matter. The reduced cognitive load translates directly into faster incident response, better-informed operational choices, and a more efficient Day 2 experience for teams managing mission-critical SAP environments on AWS.

This collaboration represents a direct investment in customer outcomes. We are building toward a future where SAP Administrators spend less time firefighting and more time driving business value — with AI handling the operational heavy lifting at the intersection of application and cloud.
