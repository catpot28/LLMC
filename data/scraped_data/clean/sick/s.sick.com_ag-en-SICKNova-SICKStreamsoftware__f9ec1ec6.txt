SICK Nova 2.15 - Highlights
SICK Nova version 2.15 is packed with new tools and features that will elevate the SICK Nova experience to a completely new level.
Let us introduce some of the highlights:
The SICK Nova Intelligent Inspection toolset license is for the first time available for 3D devices (2D data only in this release). Combine the power of AI-assisted tools such as AI Anomaly Detection or AI Object Detection with rule-based tools for height-data verification.
Speaking of AI, don't miss out on the AI-powered AI Blob Finder (dStudio) tool. The tool uses instance segmentation technology – to detect, count, and measure objects within a defined region using a trained neural network – and returns precise masks of each object at the pixel level and is ideal in cases where objects may overlap significantly. The release also makes it possible to filter on specific classes and adds class thresholds for width and height.
Check out the latest improvements in the AI OCR Pretrained tool like Date verification functionality, added threshold for number of read characters and support for additional characters. For Nova Ruler3000, a new tool, AI OCR Pretrained (2D) is added, supporting dot print reading.
Discover the brand new tools: For network convenience, we introduce the Network tool, which enables viewing and/or changing the settings of the Ethernet interfaces on the device. Struggling with 3D inspections of curved surfaces? Check out the new Surface Fitter tool. With the new Position Verifier tool, positions of found objects from a Finder or Object Detection tool can be stored as reference and easily compared for verification.
Last but not least, experience the latest update of the Dashboard, it now allows thresholds to be editable directly in Run-mode (with added permission functionality). A lock has also been added to the dashboard to only allow interaction of widget content in already defined widgets.
Enjoy this and much more with SICK Nova 2.15.

AI Blob Finder (dStudio) tool

The AI Blob Finder (dStudio) uses instance segmentation technology to detect, count, and measure objects within a defined region using a trained neural network. It identifies and separates each object in an image, pixel by pixel—even when multiple objects of the same type overlap significantly—providing precise masks rather than bounding boxes.
This capability enables accurate measurement of length, width, and area, making it ideal for quality control tasks such as counting, sorting, positioning, and defect analysis. It can also deliver high-precision size data for cracks or surface flaws and determine material quantities with exceptional accuracy.

Position Verifier tool

The Position Verifier tool compares the positions of a set of detected objects
against an internal reference list of expected objects. For each reference
object, the tool outputs if and where a corresponding live object was
found. A parent locator tool can provide a position reference.

Job specific Dashboard
Every job will now have a separate dashboard that can be configured with widgets that match the job. When duplicating a job, the dashboard will be copied as well.

AI OCR Pretrained – Improvements
A number of improvements have been made to the AI OCR Pretrained tools.
It is now possible to disable reading spaces. Found text regions can be filtered based on the character size. Text regions containing single characters can now be found in the search step (previously single characters could only be read if search was disabled). The tools can now find smaller text regions than before.
And last but not least, in 3D you sometimes need to mirror the image when using the AI OCR Pretrained tool to be able to read the text, due to scan direction. Also the OCR region needs to be aligned in a certain direction to read the text robustly. Now the AI OCR Pretrained tool contains region marker indicating how the region should be rotated to be correctly aligned with the text, that makes the usage more simple!

Full-screen viewer page
The URL
http://<ip>/#/viewer?hideShell=true&viewerMode=2D
can be used to access a full-screen 2D viewer page (viewerMode can be changed to 3D in a 3D product).
For more information about supported query parameters, see the "Nova UI API" section in the Nova API documentation.

AI Object Detection Multi-class

The AI Objection Detection tool available in the
SICK Nova Intelligent Inspection
license is used to find, count and localize – all at once, using the same tool. This standardized functionality makes it ideal for applications such as completeness checks. It ensures that the objects are in the correct position and are present in the proper amount and without any defects before the production or packaging process continues. Furthermore, it is the go-to solution when the number of objects in an image can vary, or when they may overlap.
The AI Object Detection tool also supports on-device Multi-class object detection, allowing for even more applications to be solved with ease simply by teaching the vision sensor multiple object classes within a few images.
The AI Object Detection
(dStudio)
tool supports training using the SICK dStudio service and is used to detect (i.e. find) objects in acquired images. The resulting objects are found as bounding boxes which are characterized by their class, size and position.
