The AI Objection Detection tool available in the
SICK Nova Intelligent Inspection
license is used to find, count and localize – all at once, using the same tool. This standardized functionality makes it ideal for applications such as completeness checks. It ensures that the objects are in the correct position and are present in the proper amount and without any defects before the production or packaging process continues. Furthermore, it is the go-to solution when the number of objects in an image can vary, or when they may overlap.
The AI Object Detection tool also supports on-device Multi-class object detection, allowing for even more applications to be solved with ease simply by teaching the vision sensor multiple object classes within a few images.
