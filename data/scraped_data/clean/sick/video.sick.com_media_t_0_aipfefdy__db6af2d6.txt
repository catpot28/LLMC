The AI OCR Pretrained tool enables instant reading without training and is the first AI-tool to be introduced into the Quality Inspection toolset, - which marks a shift for our rule-based portfolio where also rule-based tools can be AI-powered.
With the SICK Nova 2.13 version of the AI OCR Pretrained tool, dot print reading support is added - just easy as if it was standard characters.
This version also adds:
"Tune performance” button to automatically set downsample parameters
Support for Multiple Regions (including negative Regions)
