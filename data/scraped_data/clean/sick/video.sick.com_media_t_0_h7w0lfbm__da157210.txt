Discover SICK Nova in three dimensions — a focused insight into 3D capabilities in SICK Nova, supported 3D sensors, and their use cases in industrial automation.
In this video, Daniel Schimanek, Head of Training & Education in Autonomous Perception, explains the differences between the Ruler3000, Visionary-T Mini, and LMS4000 LiDAR sensor, helping you understand when to use which sensor based on your application needs.
The live demonstration features SICK Nova in an empty box control application using the Visionary-T Mini, showcasing how to navigate and analyze 3D data within SICK Nova in just a few simple steps.
🔍 Featured topics:
Supported 3D sensors from SICK
Visionary-T Mini in action
Empty box detection
3D data visualization and navigation
Sensor selection guidance
SICK Nova is an AI-capable foundation software designed to simplify machine vision applications.
