Zurück

Combine AI-powere 2D tools with rule-based 3D tools.
The tool AI Object Detection (dStudio) is used to detect, i.e. find, objects in acquired images. The use of the tool AI Object Detection (dStudio) requires that a trained neural network is uploaded prior to starting the detection. The resulting objects are found as bounding boxes which are characterized by their class, size and position.
The tool AI Object Detection (dStudio) enables the usage of trained neural networks from SICK dStudio. For more information about how to get your own network, visit
https://dstudio.cloud.sick.com/
.
The tool Probe Height creates a reference point in the image, based on coordinates set by the user. The reference point allows inspecting the height value of a point in the image, based on coordinates set by the user. For robustness, it uses a small region to estimate the value.
