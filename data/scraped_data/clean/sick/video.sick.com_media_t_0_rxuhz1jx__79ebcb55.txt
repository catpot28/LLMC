With the For-Each functionality, parent tools such as Blob Finder, Blob Finder Color, AI Object Detection, and AI Object Detection (dStudio) can easily be equipped with child tools, enabling in-depth inspection capabilities for each object within the inspection scene. Child tools will run relative to every found blob/object and produce a list result.
