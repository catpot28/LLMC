JAVA Foodservice

De synergie tussen het lokaal gewortelde bedrijf JAVA Foodservice en de internationale kracht van Sligro Food Group biedt het best passende assortiment en een partner in groei en ontwikkeling voor al onze klanten en stakeholders.

JAVA Foodservice
JAVA Foodservice is hét Belgische foodservicebedrijf voor foodprofessionals binnen de zorgsector, de overheid, defensie en het onderwijs.
